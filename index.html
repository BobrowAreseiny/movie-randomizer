Quick actions
Local-first · your data stays in this browser · Metadata from Letterboxd

Add a film

Enter a title and year, or paste a Letterboxd film link.

A film link like letterboxd.com/film/the-matrix/ adds the film instantly. Details are loaded in the background when possible.

Clear the whole collection?

This removes every film from the queue and from the watched archive. This action cannot be undone.

Library & data

Letterboxd is the source of metadata. The scraper runs on their site, so no API key is needed.

Scraper bookmarklet

Pin the scraper to your bookmarks (favorites) bar Drag the green button into the bookmarks bar. On a phone, tap it instead to copy the code.
Get films
  1. Open any Letterboxd list in detail view and click the pinned bookmark.
  2. Wait while the list and every film detail page are collected. Progress appears in the corner of the page.
  3. Import the downloaded letterboxd-*.json below, or via File. Watched films stay in the archive.
Show bookmarklet code
Import the collected JSON Drop the downloaded file here, or choose it manually.

Display

Poster URLs point to the Letterboxd CDN. If a film has no artwork, its hash block is used instead.

Network fallback

Only the list is imported this way. For synopses, ratings and images, use the bookmarklet.

Library data

Refreshes posters and details for films that already have a Letterboxd link.

Export & restore

Downloads are plain text. The starter list restores the built-in collection.

Import & maintenance

TXT, CSV or JSON for import. Clear all removes both the queue and the archive.
